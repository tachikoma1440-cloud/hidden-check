# 隠し命令チェッカー（仮称）

AI に文書を渡す前に、**人に見えないのに AI には読める文字**が混ざっていないかを調べる、小さなローカルツールです。

> **検出なしは、安全ではありません。** 見える文字で書かれた命令、画像の中の文字、フォントの細工は検出できません。
> **患者情報を含む文書を、外部の AI に渡してよいことにもなりません。**

## できること

| 対象 | 調べるもの |
|---|---|
| PDF | 背景と同化した文字／図形で覆われた文字／初期状態で非表示のレイヤー／極小の文字（2pt 未満）／ページの外の文字／不可視の描画モードの文字／ほぼ透明な文字／長すぎるメタデータ |
| Word（.docx） | 非表示に設定された文字／極小の文字／白い文字／ヘッダー・フッター・コメント内の同様の文字 |
| 貼り付けた文章 | Unicode タグ文字／ゼロ幅文字などの連続／双方向制御文字 |

- この PC の中だけで動きます。通信するコードは含まれていません。
- 調べた文書は保存しません（一時ファイルも作りません）。結果の保存は、画面の「結果を保存」を押したときだけです。

## できないこと

- 見える文字で書かれた命令
- 画像の中の文字、フォントの細工
- HTML、メール本文
- 暗号化された PDF、壊れた PDF、DTD を含む Word

## 必要なもの

- Python 3（作者は 3.13.13 で試験）
- PyMuPDF（作者は 1.28.2 で試験）：`pip install pymupdf`
- 画面（GUI）には tkinter が必要です（Python に標準で付属）

## 使い方

```
python -I hidden_check_gui.py                       # 画面を開く
python -I hidden_check.py ファイル名.pdf             # コマンドで調べる（複数可）
python -I hidden_check.py --json ファイル名.docx     # JSON で出す
```

結果は「重大」「注意」「情報」の3段階です。**「重大」は、悪意があるという意味ではありません。**
学術論文の PDF では、図の書き出しで残った無害な見えない文字が、「重大」と出ることがあります。出たら、場所（ページ）を開いて、人が確かめてください。

結果の種類ごとの読み方、限界の詳しい説明、試験の記録、3つ組のチェックリストは、note の記事の有料エリア（手順書）にまとめています。
記事：note「ネットから拾ってきた文献に、AI への命令が隠れていたら。医療者が AI エージェントを使う前の3つの確認」（当直明けのK）

## 試験用のファイル

`make_samples.py` は、合成の試験ファイルを作ります（隠し文字は無害な目印だけで、命令文は含みません）。
`pip install python-docx` が追加で必要です。

```
python -I make_samples.py 出力フォルダ
```

## 注意

- 試験は、合成のファイルと、公開されている文書（行政文書、論文）だけで行いました。実際の院内資料では試験していません。誤検出の率は言えません。
- Issue などに、**患者情報・院内の資料・実在の個人や施設が分かるものを貼らないでください。**
- 医療上の判断には使わないでください。現状のまま提供します。使った結果について、作者は責任を負いません。
